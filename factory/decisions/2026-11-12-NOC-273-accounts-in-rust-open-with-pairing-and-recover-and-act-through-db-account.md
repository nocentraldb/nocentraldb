# 2026-11-12 · NOC-273 · Accounts in Rust open with `OpenOptions::pairing()` or `recover(words)` and act through `db.account()`, and the recovery code is a redacted `RecoveryCode` kept until `confirm()`

- Decided by: Carsten (2026-11-12, on NOC-273, questions 1 to 4, A each)
- Why: RFC 0010 decided how accounts work and RFC 0009 named only their TypeScript calls. Opening uses two builder methods, as `agent()` does; wrong or misspelt words fail with `invalidValue` and create nothing. `db.account()` returns `Account`, as `db.spaces()` and `db.sync()` do: `pair(PairKind, &invitation)` returns the answer, one notice per space the new device was added to, and the spaces whose admins the app must ask (TypeScript's `db.account.pair` returns the same three); `complete_pairing(&answer)` returns this device's notices; `remove_member(member, &words)` takes the recovery code, because that step makes a new account key (TypeScript: `removeMember(memberId, { recover: words })`). `PairKind` is `Device` or `Agent`, since `MemberKind` also contains `SubAgent`, which nobody pairs. `RecoveryCode` shows `RecoveryCode(redacted)` in its printed and debug forms, has no serde, gives the twelve words only through `words()`, and `confirm()` uses it up. The first ordinary open creates the account and its code, kept in the keystore until `confirm()`, and `recovery_code()` returns it on every open until then, so an app that crashed before showing it shows it next time. Two of these change RFC 0009's text: `pair` returns more than the answer, and `removeMember` takes the recovery code.
- Instead of: one `OpenOptions::mode(Mode)` (1B) or separate entry points such as `Db::recover` (1C); `pair` returning only the answer (2B), which hides the spaces the device joined; `remove_member` without the code and a second call to renew the key (2C); serde writing `"redacted"` (3B); the code only as a return value of the creating open (4B) or as a notice or event (4C).
- Topics: accounts, pairing, recovery, public-names, sdk-rust, sdk-ts, rfc-0009, rfc-0010
