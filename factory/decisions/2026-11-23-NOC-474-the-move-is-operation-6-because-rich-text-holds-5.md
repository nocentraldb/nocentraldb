# 2026-11-23 · NOC-474 · The move is operation 6, because rich text holds 5

- Decided by: pm, carrying out RFC 0016 against RFC 0013 (NOC-474, #474)
- Why: RFC 0013, merged first, gives operation 5 to the rich-text update. RFC 0016 meant the first free number of RFC 0004's reserved range for the move, and that number is 6. The reserved range is now 7 to 63.
- Instead of: renumbering rich text, which RFC 0013 had already fixed.
