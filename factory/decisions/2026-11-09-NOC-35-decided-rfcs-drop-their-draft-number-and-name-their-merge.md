# 2026-11-09 · NOC-35 · Decided RFCs drop their draft number and name their merge

- Decided by: coding agent (NOC-35)
- Why: the header lines of RFC 0002 to 0007 still read "DRAFT 0.1", and the status of RFC 0002, 0007 and 0008 still said the RFC "is final when this pull request is merged"; both read as undecided after the merge. The headers now drop the draft number, as RFC 0008's already did, and each status names the merge with its PR and date, so no merged RFC says "Draft" or waits for itself.
- Instead of: changing only the status lines of RFC 0003 and RFC 0006 that the ticket names, or a new header label such as "DECIDED" that no RFC uses yet.
- Topics: rfc, docs
