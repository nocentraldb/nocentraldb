# 2026-11-27 · NOC-552 · An index through a cross-space reference is member-local information, as a reference's state is

- Decided by: Carsten, 2026-11-27, on RFC 0018's open questions, through pm (NOC-552)
- Why: It makes the private filing of a shared project queryable by the project's fields; it never enters a change, shared state, a computed field or a view.
- Instead of: Refusing indexes through a reference, or allowing them only through in-space references.
- Topics: rfc-0018, indexes, references, convergence
