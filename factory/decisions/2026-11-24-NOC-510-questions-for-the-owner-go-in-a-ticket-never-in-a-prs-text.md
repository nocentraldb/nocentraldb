# 2026-11-24 · NOC-510 · Questions for the owner go in a ticket, never in a PR's text

- Decided by: Carsten, 2026-11-24, in the pm session
- Why: a question in a PR's text is lost once the PR merges, cannot be tracked or listed in the daily note, and mixes a decision into a code review. A ticket for the owner keeps the options, the answer and who decided in one place.
- Instead of: letting coding agents ask the owner in a "For the owner" section of the PR's text, as PR #476 did.
- Topics: factory, owner-questions, pull-requests
