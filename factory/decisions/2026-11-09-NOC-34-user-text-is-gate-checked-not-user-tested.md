# 2026-11-09 · NOC-34 · "Tested" text for end users means checked by the gate; no user has read it yet

- Decided by: coding agent (NOC-34)
- Why: the ticket asks for short, tested wording. A test with users is outside what an agent can run, so the gate checks what can be checked: each text names the app with `{appName}`, has at most 60 words, uses only the placeholders `{appName}` and `{count}`, has a form for one unsaved change and for more, and uses no promise word (never, always, guaranteed, safe, secure, forever, permanent). The page says plainly that no user has read the texts yet.
- Instead of: calling the wording tested without saying how, which would claim more than was done (principle 4).
