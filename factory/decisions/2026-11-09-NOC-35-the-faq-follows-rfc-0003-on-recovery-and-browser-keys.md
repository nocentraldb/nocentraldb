# 2026-11-09 · NOC-35 · The FAQ follows RFC 0003 on account recovery and browser keys

- Decided by: coding agent (NOC-35)
- Why: the FAQ's lost-device answer said a passkey unlocks the browser's key and that recovery after losing every device was still open; RFC 0003 decided a non-exportable WebCrypto key in the browser and the account key on every device plus a recovery code (decision 8, Carsten, 2026-11-08). Rewriting the answer for RFC 0006 would otherwise have kept two sentences the merged RFC contradicts.
- Instead of: leaving both sentences for another ticket, which would leave the FAQ promising less, and a different design, than the RFC.
