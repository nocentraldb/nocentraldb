# 2026-11-20 · NOC-361 · The TypeScript API reference is a docs page rendered from the SDK's API report

- Decided by: pm, 2026-11-20 on NOC-361 (option A of three)
- Why: `packages/sdk/etc/api-report.d.ts` is already kept equal to the SDK's public declarations by the `api-report` gate, so a page built from it at `/docs/api/reference/`, one section per module, is never older than the SDK and needs no new dependency. It shows declarations only, because the report removes comments; `/docs/api` says what the main calls do.
- Instead of: a link to the report on GitHub, or pages generated by TypeDoc, which adds a dependency and a second build of the SDK and shows no more without doc comments.
- Topics: site, docs, sdk-ts
