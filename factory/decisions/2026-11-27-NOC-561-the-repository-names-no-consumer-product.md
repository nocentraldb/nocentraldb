# 2026-11-27 · NOC-561 · The repository names no product that uses NoCentralDB

- Decided by: Carsten, 2026-11-27, in the pm session
- Why: code, tests, documentation, RFCs and decision files describe NoCentralDB for every app that uses it, not for one consumer. Where a reference helps, they say "a consumer using NoCentralDB" or "an app that uses NoCentralDB". Linear tickets may name a consumer.
- Instead of: naming the consumer whose measurement or request led to a change.
- What this does not change: the project's origin as `factory/GENESIS.md` and RFC 0001 state it, which stays with the owner; the development tool nexus-flow, which the repository's tooling names.
- Topics: docs, conventions
