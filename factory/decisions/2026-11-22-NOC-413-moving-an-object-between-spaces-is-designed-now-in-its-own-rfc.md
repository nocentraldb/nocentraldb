# 2026-11-22 · NOC-413 · Moving an object between spaces is designed now, in an RFC of its own with its notice

- Decided by: Carsten, 2026-11-22, on RFC 0015's questions, through pm (NOC-429)
- Why: sharing a single note alone depends on it; today an app can only copy the note into a new space, which gives it a new id and history and breaks links to it.
- Instead of: leaving apps to copy and delete.
- Topics: spaces, sdk-ts, sdk-rust, rfc-0015
