# 2026-11-12 · NOC-263 · A recovery code error names a word's position, never the word

- Decided by: coding agent (NOC-263)
- Why: eleven of the twelve words are most of the secret, and an error travels to logs and screens; "word 12 is not on the list" lets a person fix a typo without the error carrying any word, and a checksum error says only that a word is wrong or out of order.
- Instead of: an error that quotes the unknown word, or suggests the nearest words on the list, which would put the secret's words into whatever shows or logs the error.
- Topics: accounts, recovery, keys, redaction
